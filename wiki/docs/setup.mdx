# 0 SETUP

SETUP is scene 0, the first one and the only one outside the <Key k="ESC" /> ring: the **project** (save, load, tempo) and the **global settings** (the keyboard of every track, the device). Four pages (<Key k="CTRL" /> steps, hold CTRL for the page map):

<Page name="PROJECT" /> <Page name="FILES" /> <Page name="KEYS" /> <Page name="SYSTEM" />

| Pages | Kind | Stored |
|---|---|---|
| PROJECT · FILES | project | projects on the SD card; BPM and swing belong to the project |
| KEYS | keyboard of all four tracks | in the project (SELECT is an app preference, kept for every project) |
| SYSTEM | device settings | shared by every app, never in a project |

Chord and arpeggiator are per track, on the CHORD and ARP pages of <Scene name="INSTR" /> (see [Chord and arpeggiator](#setup-chord-arp)).

<Keywords k="setup, settings, global, settings page, preferences, options, project, files, keys, chord, arp, system, scene 0, 设置, 全局" />

## Getting in and out {#setup-open}

<Strip>
  <Step keys="hold ESC" shot="map-esc" at="cells:1,1-4,1">Hold <Key k="ESC" />: column 1 of the scene map is 0 SETUP, set apart by a dotted rule and a dim number.</Step>
  <Step keys="hold ESC + G1" shot="setup-project" at="8,0,41,11">Press any key of column 1: SETUP opens on the page you were last on.</Step>
  <Step keys="ESC" shot="instr-voice" at="scene">Tap <Key k="ESC" />: back to the scene you came from (INSTR here).</Step>
</Strip>

- A tap on <Key k="ESC" /> only walks the three music scenes 1 INSTR → 2 SEQ → 3 TAPE; it never enters SETUP (see [Scenes: ESC](./navigate.mdx#nav-scenes)).
- The FN menu has SETUP (GLOBAL) on every screen, on the bottom-right GRID key (<Key k="FN" /> + that key runs it, see [The menu on each screen](./fn.mdx#fn-menus)). Inside SETUP the same item reads BACK and the scene you came from.
- The pads keep playing the current track in SETUP, so you hear every change at once.

| GRID | Does |
|---|---|
| row 1 | **SAVE**: save now · **LOAD**: go to FILES · **NEW**: a new project with the default four tracks (asks first when there are unsaved changes) |
| row 2 | **BPM** (30–300) and **SWING** (50–75 %): tap to focus, <Key k="ADD" /> / <Key k="SUB" /> change it · **TAP**: tap it in time, the interval sets the BPM · **PLAY**: switches LOOP ↔ SONG (fully lit in SONG, see [SONG: arranging the song](./tape.mdx#tape-song)) |

- <Key k="OK" /> saves the project; with TAP focused it taps the tempo instead.
- <Key k="FN+ADD" /> / <Key k="FN+SUB" /> take big steps: BPM ±10, swing ±5. Hold BPM or SWING: the 32 pads become its values, lowest top left, highest bottom right; press one to jump there.
- An untitled project is saved as the first free name SONG 01, SONG 02…; to give it your own name use SAVE AS in the FN menu (up to 24 letters, digits, spaces and -, see [Typing text](./fn.mdx#fn-text)). A name that is already on the card asks before it overwrites (<Key k="OK" /> = yes, <Key k="ESC" /> = no).
- NEW starts with the default four tracks, C major, no chords, every arpeggiator off; SELECT stays as it was.
- The PLAY switch is a performance control: it is not saved in the project.

The FN menu of PROJECT and FILES:

| GRID | Item |
|---|---|
| row 1 | **NEW** PROJECT · **LOAD** PROJECT (goes to FILES) · **SAVE AS** PROJECT (type a name) |
| row 4 | **SAVE** (<Key k="FN+S" />, reads UNSAVED while there are changes) · **TAP** (<Key k="FN+T" />) · **REC** (<Key k="FN+PLAY" />) · **BACK** to the scene you came from |

## FILES {#setup-files}

All projects on the SD card, by name; the open one is marked `>`.

<Shot name="setup-files">
  <Mark at="content">Project list</Mark>
  <Mark at="footer">FILES: page 2 of 4</Mark>
  <Caption>SETUP FILES: the projects on the card (NO PROJECTS ON THE CARD while there are none).</Caption>
</Shot>

- <Key k="ADD" /> / <Key k="SUB" /> choose (<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 8 at a time), <Key k="OK" /> loads.
- With unsaved changes it asks first: <Key k="OK" /> loads anyway, <Key k="ESC" /> keeps your work.
- A loaded project opens on T1 and brings its own keyboard, chords and arpeggiators (a project saved by older firmware has none and keeps the current ones).
- LOAD on the PROJECT page and LOAD in the FN menu lead here too. Release 0.1.0 kept its projects in the same folder, so they are in the list (see [Folders on the SD card](./projects.mdx#storage-layout)); saved again they become format 7, which 0.1.0 cannot open.
- Without an SD card the list is empty (see [No card, or a bad card](./projects.mdx#storage-card)).

## KEYS {#setup-keys}

How the pads play, for all four tracks. The keyboard is saved with the project; SELECT is a preference of the app and stays the same for every project.

  <KeyMark keys="G1">Focus: fully lit</KeyMark>
  <KeyMark keys="G2-G7">Settings: half lit</KeyMark>
  <Caption>SETUP KEYS: seven settings and a two-octave preview of the keyboard.</Caption>
</Shot>

| Setting | Options | More |
|---|---|---|
| LAYOUT | PIANO / SCALE / CHROMA | [Keyboard layouts](./play.mdx#play-keyboard) |
| SCALE · ROOT | 14 scales · C–B | [Scale and root](./play.mdx#play-scale) |
| OCTAVE | −3 … +3 | [Octave](./play.mdx#play-octave) |
| VELO | 1–127 (default 110), the velocity of every pad | [Velocity](./play.mdx#play-velocity) |
| LOCK | OFF / MUTE / SNAP | [Scale lock](./play.mdx#play-lock) |
| SELECT | how a GRID tap selects steps on the SEQ note page (ROLL, STEP, drums): ONE: one step, a tap elsewhere moves there · MULTI: each tap adds a step or takes it out | [Selecting and editing](./seq.mdx#seq-edit) |

Both settings pages (KEYS and SYSTEM) work the same way:

| To | Do |
|---|---|
| pick a setting | tap its GRID key (the focused cell is inverse) |
| change it | <Key k="ADD" /> / <Key k="SUB" />, held they repeat; <Key k="FN+ADD" /> / <Key k="FN+SUB" /> 5 at a time |
| jump to a value | hold its GRID key: the pads are its values, lowest top left, highest bottom right |
| step a choice or a switch | tap the focused key again, or <Key k="OK" /> |
| restore the default | <Key k="FN+OK" />, or RESET in the FN menu |

Each page remembers which setting was focused.

## SYSTEM {#setup-system}

<Shot name="setup-system">
  <Mark at="cell:1,1">VOLUME (focused)</Mark>

  <Mark at="cell:1,3">SCREEN</Mark>

  <KeyMark keys="G1">Focus: fully lit</KeyMark>
  <KeyMark keys="G2 G3 G4">Settings: half lit</KeyMark>
  <Caption>SETUP SYSTEM: four device settings and a short report of the device.</Caption>
</Shot>

| Setting | Range |  |
|---|---|---|
| VOLUME | 0–100 (default 70), steps of 2 | output volume, following the ear: 0 is silent, 1 about −59 dB, 50 about −21 dB, 70 about −10 dB, 100 full; wide steps at the quiet end, fine ones at the loud end. The same as MASTER on [MIX: the mixer](./tape.mdx#tape-mix) and <Key k="FN" /> + <Key k="7" /> / <Key k="U" /> anywhere ([Quick controls: BPM, volume, octave](./fn.mdx#fn-quick)) |
| KEY LED | 0–15 (default 15) | overall brightness of the key lights; while it is focused the pads show the brightness ramp ([Brightness and the light test](./lights.mdx#lights-ramp)) |
| SCREEN | 3–100 % (default 70 %) | screen brightness |
| LOG | ON / OFF (default ON) | writes the device's log to the SD card, for when something goes wrong ([The log](./projects.mdx#storage-log)) |

These are device settings: every app on the Cardenza shares them, they are kept in `CardenzaSynth/Settings/system.cfg` on the SD card and no project carries them.

The report below is typed out line by line each time you come in: the firmware VERSION, the SD CARD (READY or NOT FOUND, see [No card, or a bad card](./projects.mdx#storage-card)), free MEMORY (on the device: internal RAM, its lowest point and the PSRAM) and the BUILD (the firmware's commit and when it was built).
