# Key lights

Every key has a single-colour light that tells you what the key can do right now. There are only three states, plus blinking:

|  |  |  |
|---|---|---|
| <Led state="off" /> | **off** | nothing there |
| <Led state="half" /> | **half lit** | something there, not chosen |
| <Led state="full" /> | **fully lit** | chosen, or happening |
| <Led state="blink" /> | **blinking** | waiting |

<Keywords k="lights, key lights, led, leds, backlight, 灯" />

| State | Means | Examples |
|---|---|---|
| <Led state="off">off</Led> | nothing there | an empty step, a key that cannot sound (a piano gap, a locked note outside the scale), a function this screen does not have, a send that is off |
| <Led state="half">half lit</Led> | something there, not chosen | a step with notes, a key that sounds, an option, a parameter, an action you can run, an existing pattern |
| <Led state="full">fully lit</Led> | chosen, or happening | the selected step, the focused parameter, the current page / scene / track / pattern, a held or sounding key, the playhead, a switch that is on (mute, solo, sequencer on) |
| <Led state="blink">blinking</Led> | waiting | a queued pattern, a cued song row, OK in a confirmation, PLAY while recording is armed |

:::note

Each key has 16 real brightness levels (driven by the device's hardware layer, CardenzaHAL). The eye does not see brightness linearly, so the firmware gamma-corrects every level first; the KEY LED setting dims them all together. The interface uses three: "half lit" is the dimmest glow a key has (1/15 of the time), "fully lit" is 100 %. No in-between levels, and no animation ever lights a key that should be off. The 8 edge keys never glow brighter than half lit: their full state shows on the screen's edge strips (see [Screen edges follow the key lights](#lights-edges)).

:::

| Screen | GRID lights |
|---|---|
| SEQ note page (ROLL, STEP and the drum machine alike) | the page on screen: empty steps off, steps with notes half lit, selected ones fully lit, the playhead runs across fully lit, steps beyond the pattern's length off; while you hold pads (nothing selected), the steps that hold their notes are fully lit |
| SEQ PATTERN | existing patterns half lit, the one in use fully lit, a queued one blinks; NEW and empty slots off |
| SEQ TRACK | the four settings half lit, the focused one fully lit |
| RECORD panel | settings half lit, REC and SNAP fully lit when on, the focus fully lit; takes half lit |
| INSTR parameter pages (CHORD and ARP too) | parameters and actions half lit, the focused parameter fully lit (HOLD fully lit while on), empty cells off |
| TAPE SESSION | each track's current pattern fully lit, the others half lit, queued ones blink |
| TAPE SONG | cells with a pattern half lit, `--` off, the selected cell and the playing row fully lit, a cued row blinks |
| TAPE MIX | the selected track fully lit; mute / solo / sequencer fully lit when on, half lit when off |
| TAPE SENDS · FX | sends that are on half lit, off ones off, the focus fully lit; FX: parameters half lit, the focus fully lit |
| SETUP PROJECT | actions half lit, the focused BPM / SWING fully lit, PLAY fully lit in SONG |
| SETUP FILES | off (choose with ADD / SUB) |
| SETUP KEYS · SYSTEM | settings half lit, the focus fully lit (with KEY LED focused the pads are the brightness ramp) |
| holding ESC | four columns, one per scene: the current scene fully lit, the other three half lit (column 1 is SETUP); the pads all off |
| holding TAB / CTRL | the keys the map accepts: the current one fully lit, the others half lit; the pads all off |
| holding FN / the FN menu | menu items half lit, a switch that is on fully lit, unavailable items and empty cells off |
| a parameter cell held | the pads are its values: one key per value half lit, the current value fully lit |
| text entry | character keys half lit; erase, OK and space half lit |

- **The pads** are always the current track's keyboard: keys that sound half lit, held and sounding keys fully lit (with the other notes of a chord, the arpeggiator's note and the notes the sequencer plays on this track), keys that cannot sound off (see [Keyboard layouts](./play.mdx#play-keyboard)). In SEQ the notes of the selected step, or while playing those of the playing step, are fully lit.
- **Drum tracks** are the one exception to the three levels: at rest their pads are half lit like any pad, but a held pad lights its column from the bottom up to its row, and a hit runs up and down its column, further the harder it is. On screen the pads keep their blocks and show how hard by dither density.
- **The four left keys**: ESC, TAB and FN half lit, CTRL half lit when the screen has pages; a held key fully lit; FN fully lit while its menu is kept open (TAB and CTRL are off then, as in every pop-up). Just after a track change only the key of that track's row lights for a moment (T1 = ESC row … T4 = CTRL row).
- **Right side**: ADD / SUB half lit when there is something to change, OK half lit when it has an action (fully lit in the SEQ STEP view), PLAY half lit when stopped, fully lit when playing, blinking while recording is armed.

While <Key k="FN" /> is held the whole keyboard shows what FN can do on this screen:

| Keys | While FN is held |
|---|---|
| GRID | the menu: available items <Led state="half">half lit</Led>, a switch that is on <Led state="full">fully lit</Led>, unavailable items and empty cells <Led state="off">off</Led> |
| PADS | the letters of the available items (<Key k="C" /> <Key k="V" /> <Key k="X" /> <Key k="Q" /> <Key k="D" />, <Key k="S" /> <Key k="T" />) and the quick controls <Key k="6" /> <Key k="7" /> <Key k="8" /> <Key k="Y" /> <Key k="U" /> <Key k="I" /> half lit; every other pad off |
| <Key k="ESC" /> <Key k="TAB" /> <Key k="CTRL" /> | ESC and TAB half lit; CTRL half lit when the scene has more than one page |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> <Key k="PLAY" /> | ADD / SUB half lit; OK half lit where the screen has an <Key k="FN+OK" />; PLAY half lit, fully lit while recording is armed |

## Screen edges follow the key lights {#lights-edges}

The 4 + 4 strips on the screen's left and right edges **are the lights of the 8 edge keys**: each strip reads its key's light at that moment. The edge keys themselves glow at most half lit, so fully lit shows only on the strip.

| Key light | Screen strip |
|---|---|
| <Led state="off">off</Led> | very faint |
| <Led state="half">half lit</Led> | 30 % dither |
| <Led state="full">fully lit</Led> | solid (the right-hand glyph turns black) |

Holds, the track hint, maps and blinking always match between screen and keys. The right strips also say more: the ADD / SUB glyphs show what they do here (▲ ▼ for a value or a list, → ← sideways, erase), and the PLAY strip is green while playing and red while recording is armed.

:::tip

When nobody plays (no key for 4 seconds), every 10 seconds a light runs down both edges: each row's left and right key lights and screen strips rise and fall together, so you see at a glance that the screen's edge strips are the keys beside them.

:::
