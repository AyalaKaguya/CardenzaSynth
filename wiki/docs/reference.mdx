## Every key at a glance {#ref-shortcuts}

**Edge keys**

| Keys | Does |
|---|---|
| <Key k="ESC" /> tap | walk the scenes 1 INSTR → 2 SEQ → 3 TAPE (in SETUP: back to where you came from; in a pop-up: cancel; in SEQ with steps selected: clear the selection) |
| <Key k="hold ESC" /> + <Key k="GRID" /> | scene map: the columns are 0 SETUP, 1 INSTR, 2 SEQ, 3 TAPE; column 1 is the way into SETUP |
| <Key k="TAB" /> tap | next track |
| <Key k="hold TAB" /> + <Key k="GRID" /> | track map, laid out like MIX: rows select / mute / solo / sequencer on-off, one column per track |
| <Key k="TAB" /> + <Key k="ADD" /> / <Key k="SUB" /> | next / previous track |
| <Key k="CTRL" /> tap | next page |
| <Key k="hold CTRL" /> + <Key k="GRID" /> | page map: every page of the scene, press one to go there |
| <Key k="CTRL" /> + <Key k="ADD" /> / <Key k="SUB" /> | next / previous page |
| <Key k="FN" /> tap | open / close the menu of this screen (it stays open; a GRID key runs an item and closes it) |
| <Key k="hold FN" /> | the same menu while held; the letters and edge keys below are its second functions |
| <Key k="ADD" /> <Key k="SUB" /> | increase / decrease, move in a list; held they repeat and speed up; on the SEQ note page with no step selected: next / previous page of the GRID |
| <Key k="GRID" /> on the SEQ note page | tap: select a step and keep it (tap again to let go); hold: selected while held; with pads held: their notes go into the step, or come out |
| <Key k="OK" /> | confirm, open, switch; on the SEQ note page a tap switches ROLL / STEP, a hold opens RECORD, with steps selected it walks NOTE → LEN → VEL → TIME |
| <Key k="PLAY" /> | play / stop |
| HOME side key | not used by the groovebox (stop all is <Key k="FN+ESC" />) |
| hold a parameter cell on the GRID | the pads become its values: press one to set it |

**FN + a key**

| Keys | Does |
|---|---|
| <Key k="FN+GRID" /> | run that item of the menu |
| <Key k="FN" /> + <Key k="6" /> / <Key k="Y" /> | BPM + / − (any screen, held it repeats) |
| <Key k="FN" /> + <Key k="7" /> / <Key k="U" /> | master volume + / − |
| <Key k="FN" /> + <Key k="8" /> / <Key k="I" /> | octave + / − |
| <Key k="FN+ESC" /> | stop all: the sequencer, every ARP and every sounding note |
| <Key k="FN+TAB" /> | previous track |
| <Key k="FN+CTRL" /> | previous page |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | big steps (BPM ±10, settings ×5); on the SEQ note page with no step selected: next / previous pattern; in lists: a page at a time |
| <Key k="FN+OK" /> | the screen's second OK: RESET (default value), SCOPE (SEQ), ADD TO SONG (SESSION), SONG / LOOP (SONG); in the sample list: rename / delete |
| <Key k="FN+PLAY" /> | record on / off (REC) |
| <Key k="FN+C" /> <Key k="FN+V" /> | copy / paste (steps, pattern or song row) |
| <Key k="FN+X" /> | clear (a whole pattern asks first) / delete a song row |
| <Key k="FN+Q" /> | quantize |
| <Key k="FN+D" /> | duplicate the pattern / the song row |
| <Key k="FN+T" /> | tap tempo |
| <Key k="FN+S" /> | save the project (a new one gets the name SONG 01, SONG 02 …) |

**FN in input screens** (lists, text fields, confirmations)

| Keys | Does |
|---|---|
| <Key k="FN" /> + <Key k=";" /> <Key k="." /> <Key k="," /> <Key k="/" /> | up / down / left / right (in a text field: cursor to the start / end, left / right) |
| <Key k="FN+F" /> | search in the preset / sample list |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | a page at a time |
| <Key k="ADD~del" /> / <Key k="FN" /> + <Key k="ADD~del" /> | in a text field (the top-right key): delete before / after the cursor |
| <Key k="OK" /> / <Key k="ESC" /> | yes / no, keep / cancel |

## Glossary {#glossary}

| Term | Meaning |
|---|---|
| Track | one of four, each with one engine, its own patterns, chord and ARP; you start on T1 |
| Engine | the synth that makes the sound: DRUMS, JUNO, DX7, SAMPLER |
| Preset / sound | a set of an engine's parameters |
| Step | the sequencer's smallest cell, a 1/16 note |
| Microstep | 6 subdivisions of a step, to record timing that is not exactly on the grid |
| Pattern | a sequence of 1 to 256 steps, shown 16 at a time; up to 16 per track |
| Song row | a part of the SONG: which pattern each track plays, for how many bars (a column on the SONG page, ROW n in the FN menu) |
| Scene | one of the four parts of the UI: 0 SETUP, 1 INSTR, 2 SEQ, 3 TAPE |
| SETUP | scene 0: project, files and the settings for every track; hold ESC + GRID column 1 |
| FN menu | what the current screen can do, on the GRID while FN is held (or kept open with a tap) |
| Take | a phrase you played, kept by capture |
| Autosave | the working state, kept on the SD card by itself, so the power can go at any time |
| GRID | the 4×4 on the right, matching the 4×4 in the middle of the screen |
| PADS | the 4×8 in the middle, always playing the current track |
| Send | how much goes to the master delay / reverb |
| Master bus | the effects after the four tracks are mixed |
