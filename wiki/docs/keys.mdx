# Keys

The keyboard has 4 rows × 14 columns in four blocks, each with its own colour and role; every key has a single-colour light that tells you what it can do **right now**. There is also a HOME key on the side, which the groovebox leaves unused.

## Left keys: ESC TAB FN CTRL {#keys-left}

All four keys work the same way: **a tap does one thing, a hold shows a map**:

| Key | <Icon name="tap" /> Tap | <Icon name="hold" /> Hold |
|---|---|---|
| <Key k="ESC" /> | walks the scenes <Scene name="INSTR" /> → <Scene name="SEQ" /> → <Scene name="TAPE" />; in <Scene name="SETUP" /> goes back; cancels in a pop-up | scene map: the GRID's four columns = the four scenes, column 1 = 0 SETUP |
| <Key k="TAB" /> | next track <Track n="1" /> → <Track n="2" /> → <Track n="3" /> → <Track n="4" /> | track map: select, mute, solo, sequencer on |
| <Key k="FN" /> | opens / closes the menu of this screen | the FN menu and second functions, see [The FN menu](./fn.mdx#fn-menu); in input screens the yellow legends, see [FN in input screens: the yellow legends](./fn.mdx#fn-yellow) |
| <Key k="CTRL" /> | next page | page map: every page of the current scene |

<Shot name="map-esc">
  <Mark at="cells:1,1-4,1">0 SETUP: only from here</Mark>
  <Mark at="cells:1,2-4,2">1 INSTR</Mark>
  <Mark at="cells:1,3-4,3">2 SEQ (current)</Mark>
  <Mark at="cells:1,4-4,4">3 TAPE</Mark>
  <Mark at="strip:ESC">ESC held</Mark>
  <KeyMark keys="ESC">Hold</KeyMark>
  <KeyMark keys="GRID">Scenes: current fully lit, others half lit</KeyMark>
  <Caption>Holding ESC: the screen becomes the scene map, and the GRID's columns are the scenes.</Caption>
</Shot>

The four strips on the screen's left edge are these four keys (top to bottom: ESC red-orange, TAB cyan, FN yellow, CTRL violet), each with its icon. Where you are is in the status line and the page tabs, not in the strips:

| Strip | Icon | Shows |
|---|---|---|
| <Key k="ESC" /> | back arrow | half lit: always works (scenes, back, cancel) |
| <Key k="TAB" /> | tab arrow | off in a pop-up; after a track change only the strip of the new track's row lights for a moment (T1 = ESC … T4 = CTRL) |
| <Key k="FN" /> | menu | fully lit while the menu is kept open |
| <Key k="CTRL" /> | pages | off when the screen has a single page or a pop-up is open |

A held key fills its strip from the bottom.

## Right keys: ADD SUB OK PLAY {#keys-right}

<Keymap>
  <Group keys="ADD SUB">Plus / minus (hold to repeat)</Group>
  <Group keys="OK">Confirm · record key</Group>
  <Group keys="PLAY">Play / stop</Group>
  <Caption>The right column: the top two set values, the bottom two act</Caption>
</Keymap>

| Key | Cap | Does |
|---|---|---|
| <Key k="ADD" /> | del | increase; up in a list; held it repeats, faster and faster |
| <Key k="SUB" /> | `\` | decrease; down in a list |
| <Key k="OK" /> | ↵ Enter | confirm, run, switch; on the SEQ note page it is the <Icon name="rec" /> **record key**: a tap switches ROLL / STEP, a hold (0.45 s) opens the RECORD panel |
| <Key k="PLAY" /> | space | play / stop; <Key k="FN+PLAY" /> arms / disarms live recording |

- With <Key k="TAB" /> held, <Key k="ADD" /> / <Key k="SUB" /> pick the next / previous track; with <Key k="CTRL" /> held, the next / previous page.
- The icons on the right strips say what ADD and SUB do on this screen: ▲ ▼ for a value and in a list alike (ADD, the upper key, raises the value and goes up the list), → ← sideways (the GRID's pages on the SEQ note page, the engine picker, with TAB or CTRL held).

:::note

In text entry the top key (the del cap) erases.

:::

<Keywords k="add, sub, plus, minus, increase, decrease, enter, ok, confirm, play, stop, 加, 减, 确认, 播放" />

## The PADS {#keys-pads}

The 4×8 keys in the middle always play the **current track**, whatever scene or page you are on. Except: while you hold ESC, TAB or CTRL (a map, the pads are silent), while you hold FN (letters and quick controls, see [Second functions (letters and the keys around)](./fn.mdx#fn-shortcuts)), while you hold a parameter cell (the pads are its values) and in the preset and sample lists (silent; search is <Key k="FN" /> + <Key k="F" />).

<Strip>
  <Step keys="hold r3c1~Kick" shot="seq-drum-held">Drum track <Track n="1" />: each **column** is one drum: kick, snare, closed hat, open hat, clap, tom, cowbell, maracas. The row says how hard: the top row hardest, the bottom row softest.</Step>
  <Step keys="hold r3c1~C3" shot="seq-hold-pad">Melodic tracks (PIANO layout): two whole octaves, rows 2 and 4 white keys, rows 1 and 3 black keys; C3 at the bottom left, the upper two rows an octave up. See [Keyboard layouts](./play.mdx#play-keyboard).</Step>
  <Step shot="text-entry">In text entry the whole keyboard types the characters on its caps.</Step>
</Strip>

<Keywords k="pads, play keys, keyboard, play notes, drums, 演奏键, 打击垫" />

## The GRID {#keys-grid}

The 16 keys of the 4×4 on the right = the 4×4 cells in the middle of the screen. **What is drawn on the screen is what the key does:**

<Strip>
  <Step keys="G2" shot="seq-step" at="116,14,113,108">Sequencer: 16 keys = 16 steps (in the STEP view the right of the screen is the same 4×4). A pattern can be up to 256 steps; the GRID shows one page of 16 at a time.</Step>
  <Step keys="G1" shot="instr-juno-vcf" at="cell:1,1">Instrument pages: 16 cells = 16 parameters; tap one to select it.</Step>
  <Step keys="G6" shot="tape-mix" at="cells:1,2-4,2">MIX: each column is one track's select, mute, solo and sequencer switches.</Step>
</Strip>

While a left key is held the GRID becomes that key's "map", see [Hold a left key = a map](./navigate.mdx#nav-maps).

<Keywords k="grid, 4x4, matrix, cells, direct keys, 网格" />

## HOME side key {#keys-home}

The HOME key on the side does nothing in the groovebox. <Icon name="stop" /> **Stop all** is <Key k="FN+ESC" />: it stops the sequencer and silences everything that is sounding (stuck notes and every ARP included), and the screen says ALL STOP.

:::note

Switching apps is the job of the device's own launcher.

:::

<Keywords k="stop all, panic, all notes off, stuck notes, silence, home, home key, fn esc, 全部停止" />

## One rule for everything {#keys-rules}

|  | Rule |
|---|---|
| <Key k="hold ESC" /> <Key k="hold TAB" /> <Key k="hold CTRL" /> | **While a left key is held, choose on the GRID.** Each cell of a map sits on the key that picks it |
| <Key k="hold FN" /> | While FN is held, **no key does its usual job**: the GRID is the menu, keys with an FN function do only that (lit), the others do nothing (off) |
| <Icon name="tap" /> | A modifier that was used in a combination does not also fire its tap when released |
| <Icon name="hold" /> | A hold is 250 ms (OK on the SEQ note page: 0.45 s); <Key k="ADD" /> / <Key k="SUB" /> start repeating after 0.4 s and move 5 at a time after 12 repeats |
