# 2 SEQ 音序器

每条轨道最多 16 个 Pattern。每个 Pattern 有自己的长度，1–256 步（开始是 16 步），GRID 一次显示其中一页 16 步。每步最多 8 个音（和弦），每个音有自己的长度、力度和微小的时间偏移（每步 6 个微步）。SEQ 有三页：

| 页 | 做什么 |
|---|---|
| <Page name="ROLL" /> / <Page name="STEP" /> 音符页 | 写音符、改音符、录音。两种视图：ROLL 钢琴卷帘，和画成鼓机样子的 STEP；鼓轨的 STEP 视图就是 <Page name="DRUMS" /> 鼓机 |
| <Page name="PATTERN" /> | 选择、新建、排队切换这一轨的 Pattern |
| <Page name="TRACK" /> | 这一轨的音序开关、当前 Pattern 的长度，全局 Swing 和 BPM |

<Keywords k="音序器, 编曲, 节奏, 循环, pattern, sequencer, sequence, steps, loop, beat" />

## 音符页的两种视图 {#seq-notes}

<Key k="OK" /> 是这一页的 <Icon name="rec" /> **录音键**：单击在两种视图之间切换，按住打开 RECORD 面板。有选中的步时，单击 <Key k="OK" /> 是换编辑项（见 [选中与编辑](#seq-edit)）。

<Strip>
  <Step shot="seq-notes" at="footer"><Icon name="roll" /> **ROLL 钢琴卷帘**：时间 × 音高，音符画成条。旋律轨从这里开始。</Step>
  <Step keys="OK" shot="seq-step-view" at="footer 116,14,113,108"><Icon name="step" /> 单击 <Key k="OK" />：**STEP**，每个音一行排在各步上面，右边是演奏区选中的那个音在 GRID 上的样子。鼓轨从这里开始：它就是鼓机。</Step>
  <Step keys="OK" shot="seq-notes" at="footer">再单击：回到 ROLL。屏幕上的 OK 色块 ROLL 时 <Led state="half" />、STEP 时 <Led state="full" />。</Step>
</Strip>

两种视图显示同一个 Pattern，**按键完全一样**，只是画法不同。鼓轨和旋律轨各自记住自己的视图。GRID 的 16 个键就是屏幕上这一页的 16 步（第 1 行是第 1–4 步，第 2 行是 5–8 步……）：

| 键 | 作用 |
|---|---|
| 单击 GRID | 选中这一步并保持，手可以离开 GRID 去弹 PADS；再点一次放开，点别的步就换到那一步（SELECT MULTI 时单击是加选） |
| 按住 GRID | 按住期间选中这一步，松开就放开；同时按住几步就一起编辑。停止时按住能听到这一步 |
| 按住 PADS + GRID | 按住的音写进这一步；这一步已经有其中任何一个音，就把它们全部去掉 |
| 有选中的步时弹 PADS | 对选中的步做同样的事：这个键的音（连同它的整个和弦）放进去，或者去掉 |
| 没有选中的步时弹 PADS | 就是弹奏（REC 打开时实时录音） |
| <Key k="ADD" /> / <Key k="SUB" /> | 有选中：调整选中的步；没有选中：长 Pattern 翻到下一页 / 上一页 |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | 有选中：大步调整；没有选中：下一个 / 上一个 Pattern |
| <Key k="OK" /> | 单击：切换视图（有选中时换编辑项）；按住：RECORD 面板 |

不会自己往前走：没有写入光标，没动过的步就是休止。

横向是这一页的各步（不到 16 步的 Pattern 也铺满宽度），纵向是音高。旋律轨上，每一行是演奏区在当前八度能弹到的一个音，不管用没用到都在，黑键行带底纹；超出这个范围的音会把它撑大（最多 41 行）。鼓轨上每一行是用到的一种鼓，写着鼓名。音符越实力度越大；绿色竖线是播放头。底部小格：有音符的步带点阵，选中的步白色，播放头所在的步绿色。

按住 PADS 时，这些音（和弦音也算）所在的行整行亮起，一眼看出点一步会写到哪里。空的 Pattern 上写着 HOLD A PAD + TAP STEPS。

**写音符：按住一个或几个 PADS，再点 GRID 上的步。**

<Strip>
  <Step keys="hold r3c1~C" shot="seq-hold-pad">按住一个音（左下角的 C3）：它那一行亮起。</Step>
  <Step keys="hold r3c1~C + G1" shot="seq-hold-tap" at="28,57,15,10">不松手，点 GRID 1：第 1 步写进 C。</Step>
  <Step keys="hold r3c1~C + G5, G9" shot="seq-notes" at="28,110,195,11">继续点 5、9……换个音再点几步。点一下已经有这个音的步，它就被去掉。</Step>
</Strip>

- **看一步**：单击它的 GRID 键，这一步的音在演奏区全亮，一眼就知道里面有什么；再点同一步放开。见 [选中与编辑](#seq-edit)。
- **实时录音**：打开 REC（<Key k="FN+PLAY" /> 或 RECORD 面板），播放，然后弹，见 [播放与实时录音](#seq-transport)。
- 这一轨的音序关掉时（TRACK 页），这一页上写着 SEQUENCE OFF - SEQ > TRACK。

- **左边**：每个音一行（旋律轨是演奏区在这个八度能弹到的每个音，最高的在最上面，黑键行带底纹；有超出的音时往外扩，最多 41 行），排在这一页的 16 步上。按着的音那一行亮起，选中的步那一列亮起。
- **右边**：演奏区上次按的那个音（名字在上方）在 4×4 GRID 上的 16 步，力度用点阵疏密表示，选中的步反显。
- 按键和所有音符页一样（见 [音符页的两种视图](#seq-notes) 里的表）。不跟节拍、一步一步地写：

<Strip>
  <Step keys="OK" shot="seq-step-view" at="116,14,113,108">单击 <Key k="OK" /> 进入 STEP 视图。</Step>
  <Step keys="G2, r3c2~D, r3c3~E" shot="seq-step" at="144,25,26,22">单击 GRID 2：第 2 步选中并保持。按 D，再按 E：两个音都放进第 2 步。再按一次 E，它就被去掉。</Step>
  <Step keys="G2">再点一次 GRID 2 放开它，或者直接点下一个要写的步。</Step>
</Strip>

- 从演奏区写进去的音用 SETUP KEYS 的力度（VELO），长度一步；鼓按它那个键所在行的力度。之后用编辑项修改（见 [选中与编辑](#seq-edit)）。
- 播放时，播放头走进的那一步绿色闪一下，然后保持绿框直到下一步；走过的步不留拖尾。
- FN 菜单和 RECORD 面板里的 VIEW 也能切换视图。

## 选中与编辑 {#seq-edit}

GRID 键**选中**它那一步。两种视图、鼓轨都一样，和 MatrixOS 的音序器相同：

- **短按**（0.25 秒内松开，期间没按别的键）：这一步保持选中，手可以腾出来。**SELECT** 是 ONE（默认）时，短按别的步就换到那一步，短按唯一选中的那一步就放开它。**SELECT** 是 MULTI 时（在 <Scene name="SETUP" /> 的 KEYS 页，见 [KEYS 键盘](./setup.mdx#setup-keys)），短按是加选，短按已选中的步是把它移出。
- **按住**（更久，或者按住时按了别的键）：只在按住期间选中。同时按住几步就一起编辑。
- <Key k="ESC" /> 取消选择；SELECT 是 ONE 时翻页也会取消。

<Shot name="seq-selected">
  <Mark at="76,15,14,96">选中的这一步</Mark>
  <KeyMark keys="G5">选中：全亮</KeyMark>
  <KeyMark keys="r3c1">这一步的音：全亮</KeyMark>
  <KeyMark keys="PADS">别的键：半亮</KeyMark>
  <Caption>选中第 5 步：这一列高亮，这一步的音在演奏区全亮。</Caption>
</Shot>

选中的步，它们的音在演奏区全亮；播放时没有选中的步，播放头所在那一步的音亮起。选中一步之后：

<Strip>
  <Step keys="G5" shot="seq-selected" at="76,15,14,96">单击 GRID 5：第 5 步选中，这一列高亮。</Step>
  <Step keys="OK, OK" shot="seq-lane" at="footer"><Key k="OK" /> 循环编辑项 **NOTE → LEN → VEL → TIME**，底行是正在改的项和数值。</Step>
  <Step keys="ADD" shot="seq-lane" at="footer"><Key k="ADD" /> / <Key k="SUB" /> 调整，按住连发。<Key k="ESC" /> 取消选择。</Step>
</Strip>

| 键 | 作用 |
|---|---|
| PADS | 把这个键的音放进选中的步，或者去掉：和弦作为一组进出（这一步只要有其中任何一个音，就全部去掉、一个也不加）；播放中只编辑，不发声 |
| <Key k="OK" /> | 编辑项 NOTE（音高）→ LEN（长度）→ VEL（力度）→ TIME（微小的时间偏移） |
| <Key k="ADD" /> / <Key k="SUB" /> | 调整，按住连发；加 <Key k="FN" /> 是大步 |
| <Key k="FN+OK" /> | 「和弦里所有的音」（ALL）和「其中一个音」（底行显示音名）之间切换编辑对象 |
| <Key k="ESC" /> | 取消选择（再按 ESC 才换场景） |

鼓轨上由演奏区选鼓，所以 NOTE 这一项不会挪动鼓（ADD / SUB 提示 PADS PICK DRUMS）；LEN、VEL、TIME 和别的轨一样。

## DRUMS 鼓机 {#seq-drums}

鼓轨（默认 <Track n="1" />）的 STEP 视图就是鼓机，页签写着 <Page name="DRUMS" />，鼓轨一进来就是它。<Key k="OK" /> 切到 ROLL，和别的轨一样，是用到的鼓的钢琴卷帘。

<Shot name="seq-drums">
  <Mark at="10,14,96,108">八种鼓 × 16 步</Mark>
  <Mark at="110,14,119,108">选中的鼓（CH）在 GRID 上</Mark>
  <Mark at="footer">DRUMS</Mark>
  <KeyMark keys="G1 G3 G5">有击打：半亮</KeyMark>
  <KeyMark keys="G2">这一步什么都没有：灭</KeyMark>
  <Caption>T1 的鼓机：左边是每种鼓的节奏，右边是选中的鼓的 16 步。</Caption>
</Shot>

- **PADS** 是鼓和力度：每一列是一种鼓，每一行是力度（最上面一行 127，往下 100、70，最下面一行 40）。按下会发声，并选定右边 GRID 显示哪种鼓。
- **按住鼓再点步**：这种鼓按这一行的力度放进这些步（已经有的就去掉）。也可以先点一步，再按鼓。
- **改一击**：选中它那一步（按住或单击），<Key k="OK" /> 选到 VEL 或 TIME，再用 <Key k="ADD" /> / <Key k="SUB" />。
- 一击有多重用点阵疏密表示，分四档，一眼分得清（实心、一半、1/4、1/8）；不在正拍上的一击画成细条，位置就是它在这一步里的位置。
- 按住鼓键时，这种鼓那一行整行亮起，亮的密度跟按下的力度走，鼓名反显。

<Strip>
  <Step keys="hold r3c3~CH + G1, G3, G5" shot="seq-drums" at="110,14,119,108">按住闭镲（CH，最下面一行），隔一步点一下：CH 按最轻的力度放进去。</Step>
  <Step keys="hold G1 + OK, OK, ADD" shot="seq-drum-edit" at="footer">按住第 1 步，单击两下 <Key k="OK" /> 选到 VEL，再按 <Key k="ADD" />：这一步的击打变重。松手后第 1 步不再选中。</Step>
</Strip>

- GRID 灯和所有音符页一样：有击打的步半亮，选中的步全亮，空步灭；按住鼓键时，含有这些鼓的步全亮。
- 实时录音和 RECORD 面板和别的轨一样用。

## 无感录制：把刚才弹的找回来 {#capture}

<Icon name="capture" /> 不用开 REC：你在演奏区弹的每一个音都会在后台记下来（Capture）。弹得好的那一段，事后放进音序器：

<Strip>
  <Step keys="r3c1~C, r3c3~E, r3c5~G" shot="seq-keyboard">随便弹。停顿超过 2.5 秒、换轨或超过 60 秒，就开始新的一段（take）。</Step>
  <Step keys="hold OK" shot="record" at="cells:2,1-3,4">按住 <Key k="OK" />：中间两行是最近 8 段 take，编号、轨道、音符数。</Step>
  <Step keys="G6" shot="record" at="cell:2,2 cells:4,1-4,4">点一个 take：第 4 行是它这一小节放进去的样子。<Key k="ADD" /> / <Key k="SUB" /> 换小节。</Step>
  <Step keys="OK" shot="record-placed" at="14,94,212,28"><Key k="OK" />：放进这一轨的**新 Pattern**，原有的一个音都不动。</Step>
</Strip>

- 8 段 take 一共能记 400 个音；记满时最旧的一段让出位置。
- 没有空 Pattern 时会提示，用 <Key k="FN+OK" /> 合并进当前 Pattern。
- 播放中弹的 take 按小节线对齐；停止时弹的 take 从第一个音开始，按当时的 BPM 计时。
- SNAP 打开时（默认）每个音对齐到最近的整步，长度也取整步；关掉则保留弹的细微时间。

## 长 Pattern 与翻页 {#seq-long}

一个 Pattern 最长 256 步；GRID 和屏幕永远显示其中一页 16 步。页码在底行右端（例如 `2/4`，自己翻过页时是黄色）。

<Shot name="fn-held">
  <Mark at="cells:3,1-3,2">PAGE − / PAGE +：第几页 / 共几页</Mark>
  <Mark at="cells:3,3-3,4">LEN − / LEN +：长度</Mark>
  <Caption>SEQ 菜单（按住 FN）：第 3 行翻页、设长度。</Caption>
</Shot>

- **设长度**：TRACK 页的 STEPS（<Key k="ADD" /> / <Key k="SUB" /> 一步，<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 跳到下一个整页），或 FN 菜单的 LEN − / LEN +：1、2、4、8、16、32、48 … 256。
- **翻页**：音符页上没有选中的步时按 <Key k="ADD" /> / <Key k="SUB" />（它们的图标是 → ←，屏幕弹出 PAGE n/m），或 FN 菜单的 PAGE − / PAGE +。
- **换 Pattern**：音符页上没有选中的步时，<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 换到下一个 / 上一个 Pattern（弹出 PATTERN n/m 和它的名字）；播放中等这一圈播完再换（NEXT PATTERN）。
- 播放时 GRID 跟着播放头一页一页翻；自己翻过页后就停在那一页，直到下一次 PLAY。有选中的步时不翻页。
- 新建的 Pattern 沿用当前 Pattern 的长度；复制的 Pattern 保留自己的长度。超出长度的步在 GRID 上是灭的。
- 只有写了音符的页才占内存。内存不够时这个音不写入，屏幕提示 MEMORY FULL - NOTE NOT WRITTEN。

- 单击一个槽：切到这个 Pattern。停止时立即切换；播放中会**排队**，等这一轨这一圈播完再切（格子显示 NEXT 和倒计时条，键灯 <Led state="blink">闪烁</Led>）。
- 单击「NEW」槽：新建一个空 Pattern（每轨最多 16 个）。
- 正在用的 Pattern 上写着有几步写了音符。

## 复制、粘贴、清除、量化 {#seq-tools}

按住 <Key k="FN" /> 用字母键，或在 FN 菜单里选（COPY、PASTE、CLEAR、QUANT、DUP，第二行写着 STEPS 还是 PATTERN）。音符页里作用于选中的步；没有选中时，以及在 PATTERN、TRACK 页，作用于整个 Pattern：

<Keymap>
  <Group keys="FN">按住</Group>
  <Group keys="C">复制</Group>
  <Group keys="V">粘贴</Group>
  <Group keys="X">清除</Group>
  <Group keys="Q">量化</Group>
  <Group keys="D">复制 Pattern</Group>
  <Group keys="T">敲速度</Group>
  <Caption>按住 FN 的编辑键</Caption>

| 键 | 作用 |
|---|---|
| <Key k="FN+C" /> / <Key k="FN+V" /> | 复制 / 粘贴（复制过才能粘贴） |
| <Key k="FN+X" /> | 清除（整个 Pattern 时会先确认） |
| <Key k="FN+Q" /> | 量化到整步 |
| <Key k="FN+D" /> | 复制 Pattern 到下一个空槽 |
| <Key k="FN+T" /> | 敲击设定速度 |

GRID 上的 SEQ 菜单，三页都一样：

| 行 | 项 |
|---|---|
| 1 | COPY · PASTE · CLEAR · QUANT |
| 2 | DUP · VIEW（ROLL / STEP）· RECORD（RECORD 面板）· SCOPE（<Key k="FN+OK" />，有选中的步时） |
| 3 | PAGE − · PAGE +（音符页，长 Pattern）· LEN − · LEN + |
| 4 | SAVE · TAP · REC · SETUP，每个画面都一样 |

菜单的更多说明见 [每个画面的菜单](./fn.mdx#fn-menus)。

:::warning

没有撤销，所以清除整个 Pattern 前一定会确认。

:::
