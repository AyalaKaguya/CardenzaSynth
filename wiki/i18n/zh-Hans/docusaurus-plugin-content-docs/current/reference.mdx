## 全部按键速查 {#ref-shortcuts}

**两侧按键**

| 按键 | 作用 |
|---|---|
| <Key k="ESC" /> 单击 | 循环场景 1 INSTR → 2 SEQ → 3 TAPE（在 SETUP 里回到进来之前的场景；弹窗里是取消；SEQ 有选中的步时先取消选择） |
| <Key k="hold ESC" /> + <Key k="GRID" /> | 场景地图：四列依次是 0 SETUP、1 INSTR、2 SEQ、3 TAPE；第 1 列是进 SETUP 的路 |
| <Key k="TAB" /> 单击 | 下一轨 |
| <Key k="hold TAB" /> + <Key k="GRID" /> | 轨道地图，和 MIX 一样排：每列一轨，各行是选中 / 静音 / 独奏 / 音序开关 |
| <Key k="TAB" /> + <Key k="ADD" /> / <Key k="SUB" /> | 下一轨 / 上一轨 |
| <Key k="CTRL" /> 单击 | 下一页 |
| <Key k="hold CTRL" /> + <Key k="GRID" /> | 页面地图：这个场景的全部页面，按哪个去哪页 |
| <Key k="CTRL" /> + <Key k="ADD" /> / <Key k="SUB" /> | 下一页 / 上一页 |
| <Key k="FN" /> 单击 | 打开 / 关闭当前画面的菜单（常驻；按 GRID 执行一项后关闭） |
| <Key k="hold FN" /> | 按住期间显示同一个菜单；下面的字母和两侧按键是它的第二功能 |
| <Key k="ADD" /> <Key k="SUB" /> | 加 / 减，在列表里移动；按住连发并加速；SEQ 音符页没有选中的步时：GRID 翻到下一页 / 上一页 |
| SEQ 音符页的 <Key k="GRID" /> | 单击：选中一步并保持（再点一次放开）；按住：按住期间选中；按着 PADS 时：把这些音放进这一步，或去掉 |
| <Key k="OK" /> | 确认、进入、开关；SEQ 音符页单击切换 ROLL / STEP，按住打开 RECORD，有选中的步时循环 NOTE → LEN → VEL → TIME |
| <Key k="PLAY" /> | 播放 / 停止 |
| HOME 侧键 | Groovebox 不用它（全部停止是 <Key k="FN+ESC" />） |
| 按住 GRID 上的参数格 | 演奏区变成它的档位：按哪个设到哪一档 |

**FN + 一个键**

| 按键 | 作用 |
|---|---|
| <Key k="FN+GRID" /> | 执行菜单里这一格 |
| <Key k="FN" /> + <Key k="6" /> / <Key k="Y" /> | BPM + / −（任何画面，按住连发） |
| <Key k="FN" /> + <Key k="7" /> / <Key k="U" /> | 主音量 + / − |
| <Key k="FN" /> + <Key k="8" /> / <Key k="I" /> | 八度 + / − |
| <Key k="FN+ESC" /> | 全部停止：音序、所有 ARP 和所有发声 |
| <Key k="FN+TAB" /> | 上一轨 |
| <Key k="FN+CTRL" /> | 上一页 |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | 大步调整（BPM 一次 10，设置 ×5）；SEQ 音符页没有选中的步时：下一个 / 上一个 Pattern；列表里：一次一页 |
| <Key k="FN+OK" /> | 这个画面的第二个 OK：RESET（恢复默认）、SCOPE（SEQ）、ADD TO SONG（SESSION）、SONG / LOOP（SONG）；采样列表里：改名 / 删除 |
| <Key k="FN+PLAY" /> | 录音开关（REC） |
| <Key k="FN+C" /> <Key k="FN+V" /> | 复制 / 粘贴（选中的步、Pattern 或编排行） |
| <Key k="FN+X" /> | 清除（整个 Pattern 会先确认）/ 删除编排行 |
| <Key k="FN+Q" /> | 量化 |
| <Key k="FN+D" /> | 复制一份 Pattern / 编排行 |
| <Key k="FN+T" /> | 敲击速度 |
| <Key k="FN+S" /> | 保存工程（新工程自动起名 SONG 01、SONG 02……） |

**输入画面里的 FN**（列表、文字输入、确认框）

| 按键 | 作用 |
|---|---|
| <Key k="FN" /> + <Key k=";" /> <Key k="." /> <Key k="," /> <Key k="/" /> | 上 / 下 / 左 / 右（文字输入里：光标到开头 / 结尾、左移 / 右移） |
| <Key k="FN+F" /> | 在音色 / 采样列表里搜索 |
| <Key k="FN+ADD" /> / <Key k="FN+SUB" /> | 一次翻一页 |
| <Key k="ADD~del" /> / <Key k="FN" /> + <Key k="ADD~del" /> | 文字输入里（右上角的键）：删除光标前 / 光标后的字符 |
| <Key k="OK" /> / <Key k="ESC" /> | 是 / 否，确定 / 取消 |

## 名词解释 {#glossary}

| 名词 | 意思 |
|---|---|
| 轨道 Track | 四条之一，每条有一个音源、自己的 Pattern、和弦与 ARP；开机在 T1 |
| 音源 Engine | 发声的合成器：DRUMS、JUNO、DX7、SAMPLER |
| 音色 Preset / Sound | 一个音源的一组参数 |
| 步 Step | 音序器的最小格子，1/16 音符 |
| 微步 Microstep | 一步里的 6 个细分，用来记录不完全对齐的时间 |
| Pattern | 一段 1 到 256 步的音序，一次显示 16 步；每轨最多 16 个 |
| 编排行 Song row | SONG 里的一段：每轨播哪个 Pattern、播几小节（SONG 页上的一列，FN 菜单里写作 ROW n） |
| 场景 Scene | 界面的四个部分：0 SETUP、1 INSTR、2 SEQ、3 TAPE |
| SETUP | 场景 0：工程、文件和所有轨道共用的设置；按住 ESC + GRID 第 1 列进入 |
| FN 菜单 | 当前画面能做的事，按住 FN 时铺在 GRID 上（单击 FN 常驻） |
| Take | 无感录制记下的一段弹奏 |
| 自动保存 Autosave | 工作状态自动存在 SD 卡上，随时可以拔电 |
| GRID | 右侧 4×4，对应屏幕中间的 4×4 |
| PADS 演奏区 | 中间 4×8，永远弹当前轨 |
| 发送 Send | 送到总线延迟 / 混响的量 |
| 总线 Master bus | 四轨混在一起之后的效果 |
