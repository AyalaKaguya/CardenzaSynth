# FN 菜单与快捷键

<Key k="FN" /> 是**当前画面的菜单**：按住它，GRID 变成这个画面能做的事的菜单，四周的键是第二功能；单击它，同一个菜单常驻打开。

<Keywords k="fn, 功能键, 第二功能, 菜单, function, menu, shift" />

|  | <Key k="hold FN" /> 按住 FN | <Icon name="tap" /> 单击 FN：菜单常驻 |
|---|---|---|
| 执行一项 | <Key k="FN" /> + 它的 GRID 键，或 <Key k="FN" /> + 它的字母 | 它的 GRID 键；执行后菜单关闭 |
| 关闭 | 松开 FN | <Key k="FN" /> 或 <Key k="ESC" /> |
| 演奏区 | 不发声；只有字母键和快捷调节起作用 | 照常弹 |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> | 大步调整（SEQ 音符页没有选中的步时：下一个 / 上一个 Pattern）和第二个 OK（见 [第二功能（字母键与四周的键）](#fn-shortcuts)） | ADD / SUB 不起作用；<Key k="FN+OK" /> 仍是第二个 OK |

- 按住的判定是 250 毫秒；更快松开就算单击。
- **每一项都有反馈**：按住 FN 点一项时，那一格变成黄色，直到松手后一会儿；屏幕最下面一行写出做了什么（例如 COPIED P01、VIEW STEP）。灰色的项在这个画面不能用，点它会写「… NOT HERE」。
- 行 1–3 属于你所在的页面；行 4 在所有画面都一样：**SAVE** 保存工程、**TAP** 敲速度、**REC** 录音待命、**SETUP**（在 SETUP 里是 **BACK**）。
- 原来的 FN 面板和它的五页没有了：设置都在 [0 SETUP 设置](./setup.mdx)，<Key k="FN" /> + <Key k="1" />…<Key k="5" /> 不再有作用。

每一格：

- 上面是**名称**，右上角黄色的是它的 FN 字母：<Key k="FN+C" /> 就是 COPY；`OK` 表示 <Key k="FN+OK" />，`PLAY` 表示 <Key k="FN+PLAY" />；
- **第二行**写作用对象（PATTERN 或 STEPS、ROW 2、音源）或状态（ROLL、120 BPM、OFF）；
- **灯**：<Led state="half">半亮</Led> 能用，<Led state="full">全亮</Led> 是开着的开关（反显：VIEW STEP、REC ARMED、PLAY SONG），<Led state="off">灭</Led> 加虚线是现在用不了（没复制过东西时的 PASTE、没有选中步时的 SCOPE）。

## 每个画面的菜单 {#fn-menus}

| 画面 | 行 1–3 |
|---|---|
| INSTR（所有页） | **PRESETS** 浏览音色 · **SAVE** / **SAVE AS** 保存 / 另存音色 · **ENGINE** 选音源 · **RESET** `OK`：焦点参数恢复默认（参数页，包括 CHORD 和 ARP）；SAMPLER 另有 **SAMPLES**（采样文件）、**RECORD**（录采样）、**PREVIEW**（试听） |
| SEQ（所有页） | **COPY** `C` · **PASTE** `V` · **CLEAR** `X` · **QUANT** `Q`：对选中的步，没有选中时对整个 Pattern · **DUP** `D`：Pattern 复制到下一个空位（最多 16 个）· **VIEW**：ROLL / STEP（鼓轨是虚线）· **RECORD**：RECORD 面板和 take · **SCOPE** `OK`：步编辑改和弦里的哪个音（有选中的步时）· **PAGE −** / **PAGE +**：长 Pattern 在 GRID 上显示哪一页（音符页，超过 16 步时）· **LEN −** / **LEN +**：Pattern 长度，1 到 256 步（1、2、4、8、16，之后每次 16 步） |
| TAPE SESSION | **LAUNCH**：发射光标所在的行 · **ADD** TO SONG `OK`：正在播的 Pattern 记成 SONG 的新一段 |
| TAPE SONG | **COPY** `C` · **PASTE** `V`（插在光标之后）· **DELETE** `X` · **DUP** `D`：光标所在的一段（ROW n）· **PLAY** `OK`：SONG / LOOP |
| TAPE MIX | **UNMUTE** ALL 全部取消静音 · **UNSOLO** ALL 全部取消独奏 |
| TAPE SENDS · FX | **RESET** `OK` |
| SETUP PROJECT · FILES | **NEW** · **LOAD** · **SAVE AS**（工程） |
| SETUP KEYS · SYSTEM | **RESET** `OK`：焦点设置恢复默认 |
| **行 4，所有画面** | **SAVE** `S`：保存工程（有改动时写 UNSAVED）· **TAP** `T`：敲速度，显示 BPM · **REC** `PLAY`：录音待命，开着时全亮 · **SETUP**：到 0 SETUP；在 SETUP 里是 **BACK**，回到进来之前的场景 |

## 快捷调节：BPM、音量、八度 {#fn-quick}

最常用的三项不用找页面。按住 <Key k="FN" />，演奏区最右边紧挨 GRID 的 2×3 块就是三对加减键，**上排加、下排减**（和右侧 ADD 在 SUB 上面一样）：

<Keymap>
  <Group keys="FN">按住</Group>
  <Group keys="6 Y">BPM + / −</Group>
  <Group keys="7 U">音量 + / −</Group>
  <Group keys="8 I">八度 + / −</Group>
  <Caption>按住 FN：6 7 8 加，Y U I 减</Caption>
</Keymap>

<Strip>
  <Step keys="hold FN + 6" shot="fn-quick" at="14,94,212,28">BPM +1（<Key k="Y" /> 是 −1）。按住连续调。</Step>
  <Step keys="hold FN + 7" shot="fn-volume" at="14,94,212,28">音量：声音太小就按 <Key k="7" />，太大按 <Key k="U" />。</Step>
  <Step keys="hold FN + 8" shot="fn-octave" at="14,94,212,28">八度：<Key k="8" /> 升、<Key k="I" /> 降。</Step>
</Strip>

<Ref kind="fn-quick" />

按住 FN 时任何画面都能用，按住连续调，新值在屏幕底部弹出，盖在菜单上面。这 6 个键在按住 FN 时 <Led state="half">半亮</Led>，按下时 <Led state="full">全亮</Led>。

## 第二功能（字母键与四周的键） {#fn-shortcuts}

<Keymap>
  <Group keys="FN">按住</Group>
  <Group keys="ESC">全部停止</Group>
  <Group keys="TAB">上一轨</Group>
  <Group keys="CTRL">上一页</Group>
  <Group keys="ADD SUB">大步调整</Group>
  <Group keys="OK">第二个 OK</Group>
  <Group keys="PLAY">录音待命</Group>
  <Group keys="C V">复制 粘贴</Group>
  <Group keys="X">清除</Group>
  <Group keys="Q">量化</Group>
  <Group keys="D">复制一份</Group>
  <Group keys="T">Tap tempo</Group>
  <Group keys="S">保存</Group>
  <Caption>按住 FN 时有第二功能的键</Caption>
</Keymap>

| FN + | 作用 |
|---|---|
| GRID | 执行菜单里这一格 |
| <Key k="ESC" /> | 全部停止：音序器、所有正在响的音和所有 ARP（ALL STOP） |
| <Key k="TAB" /> | 上一条轨道 |
| <Key k="CTRL" /> | 上一页（单按 <Key k="CTRL" /> 是下一页） |
| <Key k="ADD" /> / <Key k="SUB" /> | 大步调整：宽范围参数 ×10（BPM 一次 10），窄范围 ×3，SETUP 设置 ×5，VOICE 页一次 10 个音色，列表一次 8 行；SEQ 音符页和 PATTERN 页：下一个 / 上一个 Pattern（播放中排队；有选中的步时：大步改它们的值） |
| <Key k="OK" /> | 这个画面的第二个 OK：INSTR、SENDS、总线 FX 和 SETUP 设置页：焦点值恢复默认；SEQ 音符页：和弦里的编辑对象（全部 / 单音）；SESSION：ADD TO SONG；SONG：SONG / LOOP 切换；RECORD 面板：把 take 合并进当前 Pattern；采样列表：改名 / 删除 |
| <Key k="PLAY" /> | 录音待命（REC） |
| <Key k="C" /> / <Key k="V" /> | 复制 / 粘贴（选中的步或当前 Pattern；SONG 里是一段） |
| <Key k="X" /> | 清除（选中的步，或当前 Pattern 需确认；SONG 里删除这一段） |
| <Key k="Q" /> | 量化（选中的步或当前 Pattern） |
| <Key k="D" /> | 把当前 Pattern 复制到下一个空位；SONG 里复制这一段 |
| <Key k="T" /> | Tap tempo：连按两次以上，按间隔设 BPM |
| <Key k="S" /> | 保存工程（还没起名时不问名字，直接用第一个空着的 SONG 01、SONG 02……） |
| <Key k="F" /> | 音色和采样列表里：搜索，见 [输入画面里的 FN：黄色丝印](#fn-yellow) |
| <Key k="1" />–<Key k="5" /> | 没有作用 |

:::note

字母键只在菜单里有对应项的画面起作用（那时它半亮）；<Key k="S" /> 和 <Key k="T" /> 到处都能用。执行后屏幕底部弹出名称和结果。菜单常驻（没有按住 FN）时演奏区弹的是音，不是字母功能。

:::

## 输入画面里的 FN：黄色丝印 {#fn-yellow}

在所有弹窗里（文字输入、音色 / 采样列表、音源选择、RECORD 面板、确认框），按住 FN 不出菜单，而是用键帽上的**黄色丝印**：

<Keymap>
  <Group keys="FN">按住</Group>
  <Group keys=";">上</Group>
  <Group keys=".">下</Group>
  <Group keys=",">左</Group>
  <Group keys="/">右</Group>
  <Group keys="ADD SUB">翻页</Group>
  <Group keys="F">搜索（列表）</Group>
  <Caption>按住 FN：GRID 右下角四个键是方向键</Caption>
</Keymap>

- 音色和采样列表里演奏区不打字：<Key k="FN" /> + <Key k="F" /> 打开搜索框（最多 16 个字符），<Key k="OK" /> 按它筛选列表。<Key k="ESC" /> 先清掉搜索，再按一次 <Key k="ESC" /> 关闭列表。
- <Key k="FN+ESC" /> 在这里同样是全部停止；文字输入里除外，那里 ESC 是取消。

## 输入文字 {#fn-text}

起名字（工程、音色、采样）时整个键盘按键帽打字：

  <Mark at="203,13,28,10">字数 / 24</Mark>
  <Mark at="footer">OK 确定 · DEL 删除 · ESC 取消</Mark>
  <KeyMark keys="ADD">删除（del）</KeyMark>
  <KeyMark keys="OK">确定</KeyMark>
  <KeyMark keys="ESC">取消</KeyMark>
  <KeyMark keys="PLAY">空格</KeyMark>
  <Caption>输入名字：SAVE PROJECT AS。</Caption>
</Shot>

- 字母、数字、空格（PLAY 键，不能放在第一个）、`-`；最多 24 个字符（搜索 16 个）。SAVE AS 从当前名字开始，没有名字时是 SONG。
- 右上角键（键帽 del）删除光标前的字符；<Key k="OK" /> 确定；<Key k="ESC" /> 取消。
- <Key k="FN" /> + <Key k="," /> / <Key k="/" /> 左右移动光标，<Key k="FN" /> + <Key k=";" /> / <Key k="." /> 跳到开头 / 结尾，<Key k="FN" /> + del 删除光标后的字符。
- 光标是字符之间的竖线，在末尾时是方块。
