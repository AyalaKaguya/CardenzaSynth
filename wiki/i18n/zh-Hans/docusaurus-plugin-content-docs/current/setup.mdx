# 0 SETUP 设置

SETUP 是 0 号场景，排在最前面，也是唯一不在 <Key k="ESC" /> 循环里的场景：放的是**工程**（保存、载入、速度）和**全局设置**（所有轨道的键盘、设备）。四页（<Key k="CTRL" /> 翻，按住 CTRL 看页面地图）：

<Page name="PROJECT" /> <Page name="FILES" /> <Page name="KEYS" /> <Page name="SYSTEM" />

| 页 | 类别 | 存在哪 |
|---|---|---|
| PROJECT · FILES | 工程 | 工程存在 SD 卡上；BPM、Swing 属于工程 |
| KEYS | 四条轨道共用的键盘 | 存在工程里（SELECT 是应用偏好，所有工程都一样） |
| SYSTEM | 设备设置 | 所有应用共用，不进工程 |

和弦和琶音是每条轨道各自的，在 <Scene name="INSTR" /> 的 CHORD 和 ARP 页（见 [和弦和琶音](#setup-chord-arp)）。

## 进出 SETUP {#setup-open}

<Strip>
  <Step keys="hold ESC" shot="map-esc" at="cells:1,1-4,1">按住 <Key k="ESC" />：场景地图的第 1 列就是 0 SETUP，右边一条虚线、编号是暗的。</Step>
  <Step keys="hold ESC + G1" shot="setup-project" at="8,0,41,11">按第 1 列任意一个键：进入 SETUP，停在上次离开时的那一页。</Step>
  <Step keys="ESC" shot="instr-voice" at="scene">单击 <Key k="ESC" />：回到进来之前的场景（这里是 INSTR）。</Step>
</Strip>

- 单击 <Key k="ESC" /> 只在三个音乐场景 1 INSTR → 2 SEQ → 3 TAPE 之间循环，永远不会进 SETUP（见 [场景：ESC](./navigate.mdx#nav-scenes)）。
- 每个画面的 FN 菜单里都有 SETUP（GLOBAL）一项，在 GRID 右下角那个键上（<Key k="FN" /> + 这个键直接执行，见 [每个画面的菜单](./fn.mdx#fn-menus)）。在 SETUP 里这一项写着 BACK 和你来的那个场景。
- 在 SETUP 里演奏区照常弹当前轨，改了什么马上能听到。

<Shot name="setup-project">
  <Mark at="cells:1,1-1,3">SAVE · LOAD · NEW</Mark>
  <Mark at="cell:2,1">BPM（焦点）</Mark>
  <Mark at="cell:2,2">SWING</Mark>
  <Mark at="cell:2,3">TAP 敲速度</Mark>
  <Mark at="cell:2,4">PLAY：LOOP / SONG</Mark>
  <Mark at="8,69,224,18">工程名（保存前是 UNTITLED）· UNSAVED / SAVED</Mark>
  <Mark at="8,89,224,25">四条轨道：音源和音色</Mark>
  <KeyMark keys="G1-G3 G7">动作：半亮</KeyMark>
  <KeyMark keys="G5">焦点：全亮</KeyMark>
  <KeyMark keys="G6 G8">SWING、PLAY：半亮（SONG 时 PLAY 全亮）</KeyMark>
  <Caption>SETUP PROJECT：工程的操作、速度和播放模式，下面是工程名和四轨摘要。</Caption>
</Shot>

| GRID | 作用 |
|---|---|
| 行 1 | **SAVE** 马上保存 · **LOAD** 跳到 FILES · **NEW** 新建（默认四轨，有未保存的改动时先确认） |
| 行 2 | **BPM**（30–300）和 **SWING**（50–75 %）：点一下选中，<Key k="ADD" /> / <Key k="SUB" /> 调 · **TAP**：跟着节奏点，按间隔设 BPM · **PLAY**：LOOP ↔ SONG 开关（SONG 时全亮，见 [SONG：编排整首歌](./tape.mdx#tape-song)） |

- <Key k="OK" /> 保存工程；焦点在 TAP 上时 <Key k="OK" /> 是敲速度。
- <Key k="FN+ADD" /> / <Key k="FN+SUB" /> 大步调：BPM 一次 10，Swing 一次 5。按住 BPM 或 SWING：32 个演奏键变成它的取值，左上最小、右下最大，按一个直接跳过去。
- 还没起名的工程保存时自动用第一个空着的名字 SONG 01、SONG 02……；想自己起名用 FN 菜单里的 SAVE AS（最多 24 个字母、数字、空格和 -，见 [输入文字](./fn.mdx#fn-text)）。卡上已有同名工程时先问要不要覆盖（<Key k="OK" /> 是，<Key k="ESC" /> 否）。
- NEW 从默认的四轨开始：C 大调、没有和弦、所有琶音关闭；SELECT 保持不变。
- PLAY 开关是演奏控制，不存进工程。

PROJECT 和 FILES 页的 FN 菜单：

| GRID | 项目 |
|---|---|
| 行 1 | **NEW** PROJECT 新建 · **LOAD** PROJECT 载入（跳到 FILES） · **SAVE AS** PROJECT 另存（输入名字） |
| 行 4 | **SAVE** 保存（<Key k="FN+S" />，有改动时写着 UNSAVED） · **TAP** 敲速度（<Key k="FN+T" />） · **REC** 录音预备（<Key k="FN+PLAY" />） · **BACK** 回到来的那个场景 |

## FILES 工程文件 {#setup-files}

SD 卡上的所有工程，按名字排列；当前打开的那个前面有 `>`。

<Shot name="setup-files">
  <Mark at="content">工程列表</Mark>
  <Mark at="footer">FILES：第 2 / 4 页</Mark>
  <Caption>SETUP FILES：卡上的工程（一个都没有时写着 NO PROJECTS ON THE CARD）。</Caption>
</Shot>

- <Key k="ADD" /> / <Key k="SUB" /> 选择（<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 一次 8 个），<Key k="OK" /> 载入。
- 有未保存的改动时先问：<Key k="OK" /> 照样载入，<Key k="ESC" /> 保留现在的。
- 载入的工程从 T1 开始，并带回它自己的键盘、和弦和琶音（旧固件存的工程没有这些，保持现在的设置）。
- PROJECT 页的 LOAD 和 FN 菜单里的 LOAD 也会跳到这里。0.1.0 版的工程就在同一个文件夹里，所以也在列表里（见 [SD 卡上的目录](./projects.mdx#storage-layout)）；再保存一次就变成格式 7，0.1.0 打不开。
- 没有 SD 卡时列表是空的（见 [没插卡或卡坏了](./projects.mdx#storage-card)）。

## KEYS 键盘 {#setup-keys}

演奏区怎么弹，四条轨道通用。键盘设置存在工程里；SELECT 是应用的偏好，所有工程都一样。

  <Mark at="cell:1,3">ROOT 根音</Mark>
  <Mark at="cell:1,4">OCTAVE 八度</Mark>
  <Mark at="cell:2,1">VELO 力度</Mark>
  <Mark at="cell:2,2">LOCK 锁定</Mark>
  <Mark at="cell:2,3">SELECT 选择方式</Mark>
  <Mark at="cells:3,1-4,4">预览：音阶音带点，根音带横线</Mark>
  <KeyMark keys="G1">焦点：全亮</KeyMark>
  <KeyMark keys="G2-G7">设置：半亮</KeyMark>
  <Caption>SETUP KEYS：七项设置和两个八度的键盘预览。</Caption>
</Shot>

| 设置 | 选项 | 详见 |
|---|---|---|
| LAYOUT | PIANO / SCALE / CHROMA | [键盘排列](./play.mdx#play-keyboard) |
| SCALE · ROOT | 14 种音阶 · C–B | [音阶和根音](./play.mdx#play-scale) |
| OCTAVE | −3 … +3 | [八度](./play.mdx#play-octave) |
| VELO | 1–127（默认 110），演奏区每个键的力度 | [力度](./play.mdx#play-velocity) |
| LOCK | OFF / MUTE / SNAP | [音阶锁定 LOCK](./play.mdx#play-lock) |
| SELECT | SEQ 音符页（ROLL、STEP、鼓机）上单击 GRID 怎么选步：ONE：只选一步，点别处就换过去 · MULTI：每次单击加选一步，或把它移出 | [选中与编辑](./seq.mdx#seq-edit) |

两个设置页（KEYS 和 SYSTEM）的操作一样：

| 要做 | 怎么做 |
|---|---|
| 选设置 | 点它的 GRID 键（焦点格子反显） |
| 调整 | <Key k="ADD" /> / <Key k="SUB" />，按住连发；<Key k="FN+ADD" /> / <Key k="FN+SUB" /> 一次 5 |
| 直接跳到某个值 | 按住它的 GRID 键：演奏键就是它的取值，左上最小、右下最大 |
| 切换选项或开关 | 再点一次焦点那个键，或按 <Key k="OK" /> |
| 恢复默认 | <Key k="FN+OK" />，或 FN 菜单里的 RESET |

每一页记住自己选中的是哪个设置。

## SYSTEM 系统 {#setup-system}

<Shot name="setup-system">
  <Mark at="cell:1,1">VOLUME 主音量（焦点）</Mark>
  <Mark at="cell:1,2">KEY LED 按键灯</Mark>
  <Mark at="cell:1,3">SCREEN 屏幕</Mark>

  <Mark at="8,71,224,44">版本 · SD 卡 · 内存 · 构建</Mark>
  <KeyMark keys="G1">焦点：全亮</KeyMark>
  <KeyMark keys="G2 G3 G4">设置：半亮</KeyMark>
  <Caption>SETUP SYSTEM：四项设备设置和一份设备状态。</Caption>
</Shot>

| 设置 | 范围 |  |
|---|---|---|
| VOLUME | 0–100（默认 70），一步 2 | 输出音量，按听感分布：0 静音，1 约 −59 dB，50 约 −21 dB，70 约 −10 dB，100 最大；小音量一端步子大，大音量一端细。和 [MIX：混音](./tape.mdx#tape-mix) 的 MASTER 是同一个，任何画面也能用 <Key k="FN" /> + <Key k="7" /> / <Key k="U" /> 调（[快捷调节：BPM、音量、八度](./fn.mdx#fn-quick)） |
| KEY LED | 0–15（默认 15） | 所有按键灯的总亮度；选中它时演奏区显示亮度梯（[亮度设置与灯光测试](./lights.mdx#lights-ramp)） |
| SCREEN | 3–100 %（默认 70 %） | 屏幕亮度 |
| LOG | ON / OFF（默认 ON） | 把设备的日志写到 SD 卡上，出问题时用（[日志](./projects.mdx#storage-log)） |

这些是设备设置：鸣片上所有应用共用，存在 SD 卡的 `CardenzaSynth/Settings/system.cfg`，不会进任何工程。

下面的状态每次进来逐行打出：固件版本 VERSION、SD CARD（READY 或 NOT FOUND，见 [没插卡或卡坏了](./projects.mdx#storage-card)）、剩余内存 MEMORY（设备上是内部内存、它的最低点和 PSRAM）、BUILD（固件的提交号和构建时间）。
