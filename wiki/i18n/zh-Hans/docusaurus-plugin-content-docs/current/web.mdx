# 网页模拟器

<Icon name="web" /> 没有机器时，可以直接在浏览器里用：[cardenza-synth.203.io](https://cardenza-synth.203.io/)（或 [cardenza-synth.vercel.app](https://cardenza-synth.vercel.app/)）。它不是仿造的界面，而是同一套固件代码（Groovebox 界面、AMY 音源、音序器、存储协议）编译成 WebAssembly：屏幕、按键灯、声音和机器上一样。

<Keywords k="模拟器, 网页版, 浏览器, 在线, 没有机器, 试一试, simulator, emulator, web, browser, online, try, try it live" />

## 连接真机（USB） {#web-usb}

<Icon name="usb" /> 用 USB 线把鸣片接到电脑上（Chrome 或 Edge），打开 [入门教程](/)。不用点任何按钮：教程页面会问浏览器能不能使用 MIDI 设备，选「允许」，之后机器一接上就自动连好。

- 机器会跟着课程走：换到这一课的画面，要按的键一直闪（其他键变暗），做对了就常亮；网页上会出现「学会了」，再多试几下，然后点「下一步」。
- 你自己的东西不会动：一课开始时，机器先把工作状态存到 SD 卡上，换成一个练习工程；教程结束时（离开课程、关掉网页、拔掉线，或者 30 秒没收到网页的消息）原样恢复。教程需要机器插着 SD 卡。
- 说明书页面不会操作机器，机器照常运行。
- 拔掉线就断开，插回去自动连上。
- 它通过 USB MIDI 和机器通信（Web MIDI，包括 SysEx）：不需要装驱动，USB MIDI 和 USB 音频照常可用。之前点了「阻止」的话，在地址栏左边的网站设置里把 MIDI 设备改成允许，再刷新。

## 电脑键盘对应哪个键 {#web-keys}

<Icon name="keyboard" /> 电脑键盘按**物理位置**对应设备的 4×14 键盘，每个键帽上都标着对应的电脑键，按下时屏幕上的键会亮：

<Keymap>
  <Group keys="r0c1-r0c12">数字行 1 … =</Group>
  <Group keys="r1c1-r1c12">Q 那一行</Group>
  <Group keys="r2c1-r2c12">A 那一行</Group>
  <Group keys="r3c1-r3c12">Z 那一行</Group>
  <Group keys="ESC TAB FN CTRL">Esc · Tab · Caps Lock / 左 Shift · Ctrl</Group>
  <Group keys="ADD SUB OK PLAY">Backspace · \\ · Enter · 空格</Group>
  <Caption>电脑键盘的四行就是设备的四行</Caption>
</Keymap>

| 设备 | 电脑 |
|---|---|
| <Key k="ESC" /> <Key k="TAB" /> <Key k="FN" /> <Key k="CTRL" /> | Esc / Tab / Caps Lock 或左 Shift / Ctrl |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> <Key k="PLAY" /> | Backspace / `\` / Enter / 空格 |
| HOME 侧键 | Home |
| 没有字母的演奏键 | 右 Shift（第 3 行）· 左 / 右 Alt（第 4 行） |

- <Key k="ESC" /> 也可以用反引号键（1 左边那个）。macOS 上 Caps Lock 会锁住 <Key k="FN" />（再按一次松开）；按住左 Shift 则是松手就放开的 <Key k="FN" />。
- 也可以直接用鼠标或手指点屏幕上的键，触屏可以多点同时按。右键点一个键会把它锁住按下（方便按住 ESC、FN……再点 GRID），再右键一次松开。

## 声音 {#web-audio}

<Icon name="sound" /> 浏览器要求先点一下页面才能出声，第一次请点任意位置或「Start audio」。声音由同一个音频引擎实时合成，延迟取决于浏览器和电脑。

## 存储与采样 {#web-storage}

- 设置、工程和音色存在浏览器里（IndexedDB），目录结构和 SD 卡一样（`CardenzaSynth/…`），刷新页面后还在。清除网站数据会把它们删掉。
- 机器自动保留的工作状态（[工作状态会被保留](./projects.mdx#project-session)）浏览器也保留：边做边存，页面切到后台时也存，刷新或关闭页面后回来还在，和真机拔电一样。要留成一个工程，仍然用 <Key k="FN+S" /> 保存。
- 模拟器页面上的「Load project…」把鸣片卡上的 `.ccproj` 文件复制到浏览器里（不会覆盖已有工程，重名的自动加编号），并打开第一个；其余的在 SETUP FILES 里。
- 「Load WAV…」把电脑上的音频文件放进共用采样目录 `Samples/`，之后在 SAMPLER 的文件列表里就能选到。不是单声道 16 位 WAV 的文件（立体声、24 位、MP3……）会转换成单声道 16 位 44.1 kHz，并截到 5 秒。
