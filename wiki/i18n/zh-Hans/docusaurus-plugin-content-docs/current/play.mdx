# 演奏

演奏区（PADS）永远在弹当前轨。键盘排列、音阶、根音、八度、力度和音阶锁定四条轨道通用，在 <Scene name="SETUP" /> 的 **KEYS** 页设置（见 [KEYS 键盘](./setup.mdx#setup-keys)）。和弦与琶音（ARP）是每条轨道自己的：每条旋律轨在 <Scene name="INSTR" /> 里都有自己的 **CHORD** 和 **ARP** 页。这些都随工程保存；NEW 的工程从 PIANO、C MAJOR、没有和弦、所有 ARP 关闭开始。

  <Caption>PIANO 钢琴排列（默认）：两个完整的八度，每两行一个，黑键在白键上面；缺口不亮也不发声。</Caption>

| 排列 | 怎么排 | 灯 |
|---|---|---|
| **PIANO 钢琴**（默认） | 两个完整的八度：下面两行从左下角的 C3 开始，上面两行高一个八度；每两行里白键 C D E F G A B C 在下，黑键在上。缺口（C# 之前、E–F 之间、A# 之后）不发声 | 缺口 <Led state="off" /> |
| **SCALE 音阶** | 只放音阶里的音，从根音开始从左到右按音阶走，每往上一行高一个八度。不会弹错音 | 全部 <Led state="half" /> |
| **CHROMA 半音** | 从根音开始每个键一个半音，从左到右、从下到上 | 全部 <Led state="half" /> |

  <Step keys="G1" shot="keys-chroma" at="cell:1,1">再点：CHROMA，每个键一个半音。</Step>
  <Step keys="G1" shot="setup-keys" at="cell:1,1">再点：回到 PIANO。</Step>
</Strip>

| 灯 | 演奏区上的意思 |
|---|---|
| <Led state="half">半亮</Led> | 能发声 |
| <Led state="full">全亮</Led> | 按住的键、和弦的其它组成音、ARP 正在弹的音、音序器在这一轨弹出的音 |
| <Led state="off">灭</Led> | 发不出声 |

## 力度 {#play-velocity}

演奏区不感应力度，旋律轨每个键用同一个力度发声：KEYS 页的 **VELO**（1–127，默认 110）。录进音序器的音也用这个力度，之后可以在音符页逐步改（VEL，见 [选中与编辑](./seq.mdx#seq-edit)）。鼓轨不用 VELO，由行决定轻重（见 [鼓](#play-drums)）。

<Keywords k="力度, 轻重, 音量大小, velocity, dynamics, how hard" />

## 音阶锁定 LOCK {#play-lock}

PIANO 和 CHROMA 排列下，音阶外的键怎么办：

| LOCK | 音阶外的键 | 灯 |
|---|---|---|
| **OFF** | 照常发声 | <Led state="half" /> |
| **MUTE** | 不发声 | <Led state="off" /> |
| **SNAP** | 落到下方最近的音阶音上 | <Led state="half" /> |

## 和弦 {#play-chords}

<Scene name="INSTR" /> 的 **CHORD** 页让一个键弹出一个和弦。每条轨道有自己的和弦，换音色或换引擎时保留。鼓轨没有 CHORD 页。

<Strip>
  <Step keys="hold CTRL + G2" shot="instr-chord" at="cell:1,1">在 <Scene name="INSTR" /> 里按住 <Key k="CTRL" /> 按 G2：这条轨道的 CHORD 页。CHORD 是 OFF。</Step>
  <Step keys="G1" shot="chord-on" at="cell:1,1 9,43,170,20">点 CHORD：TRIAD。图上写着根音上的键会弹哪几个音（C3 PLAYS C3 E3 G3）。</Step>
  <Step keys="hold r3c1~C" shot="chord-held" at="cells:3,1-4,4">按一个键：三个音一起响，组成音在屏幕和演奏区上都亮。</Step>
</Strip>

- **CHORD**：OFF / TRIAD / 7TH / MAJ / MIN / SUS4 / MAJ7 / MIN7 / DOM7 / POWER / OCTAVE。TRIAD 和 7TH 在当前音阶里叠三度（音阶外的键借用大三和弦 / 属七），其余是固定和弦。
- **VOICING**：ROOT 原位 / INV1 第一转位（最低音升八度）/ INV2 第二转位（最低的两个音升八度）/ SPREAD 展开（第二个音升八度）。
- 第二行写着这个调里每一级的三和弦（字体只有大写：小三和弦写成 `D-`，减三和弦写成 `BDIM`）。
- 实时录音时，和弦的每个音都像单独的音一样录进去，ARP 也会把它们一个个弹出来。在 SEQ 音符页上，一个键的和弦作为一组放进一步或从一步里去掉（见 [选中与编辑](./seq.mdx#seq-edit)）。

## 琶音 ARP {#play-arp}

<Scene name="INSTR" /> 的 **ARP** 页：按住几个键，它们按顺序轮流发声。每条旋律轨有自己的一台 ARP 和自己的设置，几台可以同时在跑（T2 的 HOLD 琶音继续，切到 T3 再弹另一组）。

<Strip>
  <Step keys="hold CTRL + G3" shot="instr-arp" at="cell:1,1">在 <Scene name="INSTR" /> 里按住 <Key k="CTRL" /> 按 G3：这条轨道的 ARP 页。ARP OFF 时整幅图变暗。</Step>
  <Step keys="G1, hold r3c1~C + r3c3~E + r3c5~G" shot="arp-running" at="cells:3,1-4,4">点 ARP：UP。按住 C E G：几个音从下往上轮流弹。</Step>
</Strip>

<Shot name="arp-running">
  <Mark at="cell:1,1">ARP 模式</Mark>
  <Mark at="cell:1,2">RATE 速度</Mark>
  <Mark at="cell:1,3">RANGE 范围</Mark>
  <Mark at="cell:1,4">GATE</Mark>
  <Mark at="cell:2,1">HOLD 松手继续</Mark>
  <Mark at="cells:3,1-4,4">16 步的演奏顺序</Mark>
  <KeyMark keys="r3c1 r3c3 r3c5">按住的键</KeyMark>
  <Caption>ARP UP：按住 C E G，三个音从下往上轮流弹。每根柱是一步，高低是音高，宽度是 GATE；白色的柱是正在发声的那一步。</Caption>
</Shot>

| 设置 | 选项 |
|---|---|
| ARP | OFF / UP / DOWN / UP-DN / RANDOM / ORDER（按按下的顺序） |
| RATE | 1/4、1/8、1/8T、1/16（默认）、1/16T、1/32 |
| RANGE | 1–4 个八度（向上扩展） |
| GATE | 10–100 %（每个音占音符时值的多少，默认 50 %） |
| HOLD | 松手后继续；全部松开后再按会换成新的一组。点一下这一格就切换，不用先选中 |

- 按住的键（和弦展开后的每个音都算）按顺序轮流发声，最多 16 个音。第一下立刻发声。
- 停止时按 BPM 自由运行；播放时对齐节拍（1/16 跟随 Swing），按 PLAY / 停止不会断拍。
- UP / DOWN / UP-DN 从刚弹过的音继续走，到两端不重复。
- REC 打开且在播放时，ARP 弹出的音按 GATE 长度录进它那条轨道的 Pattern。
- 换轨不会停下别的轨道的 ARP。关掉 HOLD 立刻停止（只留下还按着的键）。<Key k="FN+ESC" />（全部停止）和载入工程会停下所有 ARP。

## 鼓 {#play-drums}

鼓轨（默认 <Track n="1" />）的演奏区每一**列**是一个鼓，**行**决定轻重：最上面一行最重（力度 127），往下 100、70，最下面一行最轻（40）。静止时演奏键半亮；按住时这一列从下往上亮到弹的那一行，一击沿着这一列扩散，越重走得越远。屏幕上用点阵疏密表示力度，分四档，一眼分得清。鼓不走 ARP，也不受音阶、和弦和 VELO 影响。每个鼓的音量在 INSTR 的 KIT 页（见 [DRUMS 鼓机](./instr.mdx#engine-drums)）。
