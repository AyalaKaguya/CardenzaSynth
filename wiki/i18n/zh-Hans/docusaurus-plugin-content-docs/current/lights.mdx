# 按键灯

每个键有一颗单色灯，告诉你这个键现在能做什么。只有三种状态，加一种闪烁：

|  |  |  |
|---|---|---|
| <Led state="off" /> | **灭** | 这里什么都没有 |
| <Led state="half" /> | **半亮** | 有东西，没选中 |
| <Led state="full" /> | **全亮** | 选中，或者正在发生 |
| <Led state="blink" /> | **闪烁** | 等待中 |

<Keywords k="灯, 灯光, 指示灯, 背光, led, lights, key lights, backlight" />

| 状态 | 意思 | 例子 |
|---|---|---|
| <Led state="off">灭</Led> | 这里什么都没有 | 空的步、发不出声的键（钢琴缺口、被锁定的音阶外音）、当前画面没有的功能、关着的发送 |
| <Led state="half">半亮</Led> | 有东西，没选中 | 有音符的步、能发声的键、选项、参数、能执行的动作、已有的 Pattern |
| <Led state="full">全亮</Led> | 选中，或者正在发生 | 选中的步、焦点参数、当前的页 / 场景 / 轨道 / Pattern、按住或正在发声的键、播放头、开着的开关（静音、独奏、音序开） |
| <Led state="blink">闪烁</Led> | 等待中 | 排队的 Pattern、提示跳转的编排行、确认框的 OK、录音待命时的 PLAY |

<Strip>
  <Step shot="confirm" at="10,70,104,26"><Led state="blink" /> 确认框：OK 一直闪，等你回答。</Step>
  <Step shot="tape-session-queued" at="cell:2,2"><Led state="blink" /> 排队的 Pattern：等这一圈播完。</Step>
  <Step shot="seq-recording" at="strip:PLAY"><Led state="blink" /> 录音待命：PLAY 在闪。</Step>
</Strip>

:::note

每个键有 16 档真实亮度（由设备的硬件层 CardenzaHAL 驱动），人眼对亮度不是线性的，所以固件先做伽马校正再点灯；KEY LED 总亮度另外再整体调暗。界面只用三档：「半亮」是键能发出的最暗的光（1/15 的点亮时间），「全亮」是 100 %。不用中间亮度，也不让动画把该灭的键点亮。两侧 8 个键最亮只到半亮：它们的全亮显示在屏幕两侧的色块上（见 [屏幕两侧和按键灯同步](#lights-edges)）。

:::

| 画面 | GRID 上的灯 |
|---|---|
| SEQ 音符页（ROLL、STEP、鼓机都一样） | 屏幕上这一页：空步灭，有音符的半亮，选中的全亮，播放头全亮走过，超出 Pattern 长度的步灭；按住 PADS（没有选中的步）时，含有这些音的步全亮 |
| SEQ PATTERN | 已有的 Pattern 半亮，正在用的全亮，排队的闪烁；NEW 和空槽灭 |
| SEQ TRACK | 四个设置半亮，焦点全亮 |
| RECORD 面板 | 设置半亮，REC、SNAP 打开时全亮，焦点全亮；take 半亮 |
| INSTR 参数页（CHORD、ARP 也是） | 参数和动作半亮，焦点参数全亮（HOLD 打开时全亮），空格灭 |
| TAPE SESSION | 每轨当前的 Pattern 全亮，其它半亮，排队的闪烁 |
| TAPE SONG | 有 Pattern 的格子半亮，`--` 灭，选中的格子和正在播的那一行全亮，提示跳转的行闪烁 |
| TAPE MIX | 选中轨全亮；静音 / 独奏 / 音序开着全亮、关着半亮 |
| TAPE SENDS · FX | 开着的发送半亮，关着的灭，焦点全亮；FX：参数半亮，焦点全亮 |
| SETUP PROJECT | 动作半亮，焦点 BPM / SWING 全亮，PLAY 在 SONG 时全亮 |
| SETUP FILES | 灭（用 ADD / SUB 选） |
| SETUP KEYS · SYSTEM | 设置半亮，焦点全亮（焦点在 KEY LED 时演奏区是亮度梯） |
| 按住 ESC | 四列，一列一个场景：当前场景全亮，其它三列半亮（第 1 列是 SETUP）；演奏区全灭 |
| 按住 TAB / CTRL | 地图上能选的键：当前项全亮，其它半亮；演奏区全灭 |
| 按住 FN / FN 菜单 | 菜单项半亮，开着的开关全亮，用不了的项和空格灭 |
| 按住参数格 | 演奏区是它的档位：每档一个键半亮，当前值全亮 |
| 文字输入 | 字符键半亮；删除、OK 和空格半亮 |

- **演奏区**永远是当前轨的键盘：能发声的半亮，按住和正在发声的全亮（包括和弦的其它音、ARP 弹的音和音序器在这一轨弹的音），发不出声的灭（见 [键盘排列](./play.mdx#play-keyboard)）。在 SEQ 里，选中那一步的音，或播放时正在播的那一步的音，全亮。
- **鼓轨**是三档规则唯一的例外：静止时和别的演奏键一样半亮；按住时这一列从最下面亮到按下的那一行，一击沿着这一列上下扩散，越重走得越远。屏幕上的鼓垫还是方块，力度用点阵疏密表示。
- **左侧四个键**：ESC、TAB、FN 半亮，CTRL 在有多页时半亮；按住的键全亮；菜单常驻时 FN 全亮（这时 TAB、CTRL 灭，和所有弹窗一样）。刚换轨时，只有那条轨对应的那一行亮一下（T1 = ESC 行 … T4 = CTRL 行）。
- **右侧**：ADD / SUB 有东西可调时半亮，OK 有动作时半亮（SEQ STEP 视图全亮），PLAY 停止半亮、播放全亮、录音待命闪烁。

按住 <Key k="FN" /> 时，整个键盘显示 FN 在这个画面能做什么：

| 键 | 按住 FN 时 |
|---|---|
| GRID | 菜单：能用的项 <Led state="half">半亮</Led>，开着的开关 <Led state="full">全亮</Led>，用不了的项和空格 <Led state="off">灭</Led> |
| 演奏区 | 能用的菜单项的字母键（<Key k="C" /> <Key k="V" /> <Key k="X" /> <Key k="Q" /> <Key k="D" />、<Key k="S" /> <Key k="T" />）和快捷调节 <Key k="6" /> <Key k="7" /> <Key k="8" /> <Key k="Y" /> <Key k="U" /> <Key k="I" /> 半亮，其它全灭 |
| <Key k="ESC" /> <Key k="TAB" /> <Key k="CTRL" /> | ESC、TAB 半亮；场景有不止一页时 CTRL 半亮 |
| <Key k="ADD" /> <Key k="SUB" /> <Key k="OK" /> <Key k="PLAY" /> | ADD / SUB 半亮；画面有 <Key k="FN+OK" /> 时 OK 半亮；PLAY 半亮，录音待命时全亮 |

## 屏幕两侧和按键灯同步 {#lights-edges}

屏幕左右两侧的 4 + 4 个色块**就是两侧 8 个键的灯**：每个色块读取对应键灯此刻的亮度。两侧的键本身最亮只到半亮，所以全亮只在色块上看得到。

  <Mark at="strip:ESC">ESC 色块</Mark>
  <Mark at="strip:TAB">T2 那一行：全亮 = 实色</Mark>
  <Mark at="strip:FN">FN 色块</Mark>
  <Mark at="strip:CTRL">CTRL 色块</Mark>
  <Mark at="strip:ADD">ADD</Mark>
  <Mark at="strip:PLAY">PLAY</Mark>
  <KeyMark keys="TAB">新轨道那一行</KeyMark>
  <KeyMark keys="ESC FN CTRL">灭</KeyMark>
  <Caption>刚按 TAB 换到 T2：左侧只有第二个键亮一下，屏幕上它的色块变成实色。</Caption>
</Shot>

| 键灯 | 屏幕色块 |
|---|---|
| <Led state="off">灭</Led> | 很淡 |
| <Led state="half">半亮</Led> | 30 % 点阵 |
| <Led state="full">全亮</Led> | 实色（右侧的符号变黑） |

按住、切轨提示、地图、闪烁，屏幕和键上永远一致。右侧色块还多说一点：ADD / SUB 的符号表示它们在这里做什么（调数值和列表是 ▲ ▼，横向移动是 → ←，删除），PLAY 色块播放时是绿色，录音待命时是红色。

:::tip

没人操作时（4 秒内没按键），每 10 秒有一道光从上到下扫过两侧：左右同一行的键灯和屏幕色块一起亮起再落下，让你一眼看出屏幕两边的色块对应的是两侧的按键。

:::
