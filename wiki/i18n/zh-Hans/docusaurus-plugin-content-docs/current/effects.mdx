# 效果器

每条轨道有自己的插入效果和两路发送；发送汇到两条总线（延迟、混响），最后经过总线 EQ、压缩和磁带饱和输出。

```text
引擎 → DRIVE → CRUSH → FILTER → CHORUS → 轨道推子 ─┬─→ 输出
                                                  ├─ DELAY 发送 ─→ 总线延迟 ─┐
                                                  └─ REVERB 发送 → 总线混响 ─┴→ EQ → COMP → TAPE → 输出
```

## 总线效果 {#fx-master}

TAPE 的 FX 页，属于工程（工程文件 v4 起保存）：

<Shot name="tape-fx">
  <Mark at="cells:1,1-1,4">DELAY：按 BPM 同步的磁带延迟</Mark>
  <Mark at="cells:2,1-2,4">REVERB：4 线反馈延迟网络，偏暗</Mark>
  <Mark at="cell:3,1">COMP：总线压缩</Mark>
  <Mark at="cells:3,2-3,3">EQ：低 / 高搁架 ±12 dB</Mark>
  <Mark at="cell:3,4">TAPE：磁带饱和</Mark>
  <Mark at="cells:4,1-4,4">当前速度下的回声和混响衰减</Mark>
  <Caption>总线效果 FX。</Caption>
</Shot>

- **DELAY**：TIME 是音符时值，1/32 到 1/2（默认 1/8D），跟 BPM 同步。反馈环里有 TONE 低通和 80 Hz 高通；换时值时像磁带一样滑音。743 毫秒以内的回声用 16 KB 的延迟线；更长的时值换成 32 KB 的线（最长 1.49 秒），放不下就把时值折半直到放得下。
- **REVERB**：带宽约 4.5 kHz，偏暗。
- 两路发送先抽取到 11.025 kHz 再处理，所以延迟和混响听起来偏暖、偏 lo-fi。

<Keywords k="总线, 主输出, 磁带延迟, 混响, 均衡, 压缩, master, bus, tape delay, reverb, eq, compressor, saturation" />

## 内存和 CPU {#fx-cpu}

效果器的缓冲第一次用到时才分配，不用时还回去：延迟线 16 KB（超过 743 毫秒的回声 32 KB），混响约 8.8 KB，都放在设备的 2 MB PSRAM 里；每条轨道的合唱 1 KB。

- 延迟或混响分配不到内存时那条总线静音，FX 页和信号链图上显示 NO MEM。全部效果关闭时，输出和没有效果器时逐位相同。
- 每条轨道能同时发几个音：DX7 4 个，JUNO 和 DRUMS 6 个，SAMPLER 4 个。都占满时，新的音占用较早的音的声部，先占已经松开的。
- 音频每 256 帧的预算是 5.8 毫秒，芯片的两个核一起算。一块来不及算完时，设备把最不要紧的音淡出：总是从同时发声最多的那条轨道里挑，先是已松开的尾音，再是最轻的按住的音。一条轨道只会给自己让路，节拍不会变慢，也不会停。

:::warning

很密的和弦叠加很多效果时可能出现爆音：先减少同时发声的音，或关掉一两个效果。

:::
